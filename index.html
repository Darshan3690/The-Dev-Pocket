Engineered for Safe Agentic Development

Four layers of protection between your editor and remote CI.

🪞

CI Twin Engine

Parses GitHub Actions workflows into a local model. Compares runtime versions, packages, and OS environments.

🪟➡️🐧

Casing Guard

Checks relative import casing against disk. Catches Windows NTFS vs. Linux ext4 traps before pushing.

🚫

Anti-Cheat Auditor

Audits git diffs for stripped assertions, skipped test suites, @ts-ignore, or altered workflow configs.

🔌

Native MCP Server

Exposes Model Context Protocol tools over stdio so Cursor, Claude Code, and Antigravity verify fixes autonomously.

CLI Command Reference

Simple, targeted developer commands.

Command Options Description
vibeci analyze — Parses workflows & builds .vibeci/ci-twin.json
vibeci preflight --strict, --copy-pr-badge Full pre-PR gap scan + casing checks
vibeci check --all, --fast, --allow-build Change-aware CI check execution with safety policy
vibeci verify — Anti-Cheat Git Diff Audit (staged & unstaged)
vibeci explain — Classifies latest failure coordinates and readiness score
vibeci repair --failure-id, --root-cause Evidence-driven repair loop from latest failure report
vibeci mcp — Starts stdio JSON-RPC 2.0 MCP server for AI IDEs

Add VibeCI to Cursor / Claude Code

Add VibeCI to your MCP configuration so your coding assistant queries the CI Twin and audits repairs autonomously.

  "mcpServers": {
    "vibeci": {

How to Contribute & Verify

We welcome open-source contributions! Follow these steps to build and verify.

STEP 01

Fork & Clone

Clone repository to your local machine.

git clone https://github.com/<user>/The-Dev-Pocket.git
cd The-Dev-Pocket
STEP 02

Install & Build

Install dependencies and compile CLI.

npm install
npm run build
STEP 03

Run Local Verifications

Ensure all safety checks pass clean.

node ./dist/index.js preflight
node ./dist/index.js check --fast
node ./dist/index.js verify
